# Home SOC Lab

## Overview
Built a home SOC lab using:
- Kali Linux
- Windows 11
- Sysmon
- VirtualBox

Goals:
- Learn virtualization
- Generate endpoint telemetry
- Simulate attacks
- Analyze security logs

---

## Current Lab Architecture

Personal PC (Host)
│
├── Kali Linux VM
└── Windows 11 VM

## Tools Used
- VirtualBox
- Kali Linux
- Sysmon
- Nmap
- Windows 11
